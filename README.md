# qr_reader
Just a simple QR code reader so I can use it on PC

## Chrome 擴充功能安裝教學

### 方法一：開發人員模式（推薦，適合自己同朋友）

1. 下載本專案（點右上角 Code → Download ZIP）
2. 解壓縮後，找到 `extension` 資料夾
3. 打開 Chrome，網址列輸入：`chrome://extensions/`
4. 右上角打開「**開發人員模式**」
5. 點「**載入未封裝項目**」
6. 選擇剛剛的 `extension` 資料夾
7. 完成！工具列會出現圖示，點擊即可使用

### 使用方式
- 點擊擴充功能圖示打開
- 直接 `Ctrl + V` 貼上截圖
- 或點「上傳圖片」
- 或點「掃描」使用相機
- 解讀成功後會即時顯示內容（支援網址、文字、簡訊、電話、Email、WiFi）
